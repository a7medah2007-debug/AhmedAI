# أحمد AI - الرفيق والوكيل الصوتي الذكي للأندرويد
مشغل هاتف شامل ومستقل (Universal Mobile UI Agent) مدعوم بنموذج `DeepSeek-V3 API`، يتحدث باللهجة المصرية الطبيعية وينفذ المهام عبر الشاشة بدون لمس.

---

## 🌟 المميزات الرئيسية
1. **التحكم الشامل في أي تطبيق (Universal UI Automation)**:
   - فتح أي تطبيق مثبت على هاتفك (يوتيوب، واتساب، متصفح، فيسبوك، إعدادات، إلخ).
   - قراءة الشاشة وفهم الأزرار والنصوص وحقول البحث والضغط عليها آلياً.
2. **المسار السريع (Fast-Path Shortcuts)**:
   - ضبط المنبهات المباشرة بنظام أندرويد.
   - إرسال رسائل واتساب تلقائياً.
3. **توفير التكاليف والسرعة الفائقة**:
   - استخدام واجهة `DeepSeek-V3` السريعة مع كاش الأوامر.
   - استهلاك شبه معدوم لرام ومعالج الهاتف (الرام المستهلكة أقل من 100 ميجابايت).
4. **زر عائم ذكي (Floating Companion Bubble)**:
   - يظهر فوق كل التطبيقات لطلب أي خدمة بلمسة واحدة.
5. **البناء التلقائي عبر السحابة (GitHub Actions CI/CD)**:
   - لا حاجة لتثبيت `Android Studio` على جهازك؛ كل تحديث يتم رفعه على مستودعك في جيت هاب يُنتج ملف `app-debug.apk` تلقائياً وجاهزاً للتحميل المباشر.

---

## 🚀 كيفية بناء ملف الـ APK وتحميله
بمجرد رفع هذا المجلد إلى مستودع جيت هاب الخاص بك:
1. اذهب إلى تبويب **Actions** داخل مستودعك على GitHub.
2. ستجد سير العمل **Build Ahmed AI APK** يعمل تلقائياً.
3. عند اكتمال البناء (خلال دقيقتين)، اضغط على التشغيل وستجد ملف:
   `AhmedAI-Companion-Debug-APK`
   في قسم **Artifacts** بالأسفل.
4. حمله على هاتفك وثبته مباشرة!

---

## 📱 بعد التثبيت على الهاتف
1. افتح التطبيق وأدخل مفتاحك الخاص بـ: `DeepSeek API Key` واضغط "حفظ وتفعيل".
2. فعل **صلاحية إمكانية الوصول (Accessibility)**: ابحث عن "أحمد AI" واضغط تفعيل (هذه هي الأيدي التي تنفذ الأوامر).
3. امنح إذن **الظهور فوق التطبيقات (Overlay)** وإذن **الميكروفون**.
4. اضغط على الزر العائم أو "تكلم مع أحمد الآن" واستمتع برفيقك الذكي!
